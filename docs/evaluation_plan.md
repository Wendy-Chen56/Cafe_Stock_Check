# Evaluation Plan

## What I want to check

I want to find out whether the report makes it easier to identify supplies that need ordering. I also want to know whether someone can follow the README and understand the results without much help.

I’ll ask a classmate or the instructor to try it and give me feedback. No feedback has been recorded yet.

## How I’ll check it

1. Give the reviewer the README and sample inventory file.
2. Ask them to run the program and find the items that need attention.
3. Ask them to explain why Whole milk is ORDER SOON and Matcha powder is REORDER NOW.
4. Have them export the list and check whether they can find and open the CSV.
5. Ask which instructions, labels, or results were confusing.
6. Record what happened and decide whether anything needs to change. If I make a change, I’ll check it again.

The reviewer should try the task before seeing the answer list below. I’ll note any help I give them.

## Expected results

With the default three-day warning, seven items should appear:

- Cold brew concentrate
- Caramel syrup
- Matcha powder
- Sanitizer wipes
- Whole milk
- 12oz cups
- Espresso beans

Whole milk is ORDER SOON because it has only 1.8 days of stock left, even though it is above its reorder level.

Matcha powder is REORDER NOW because its stock is below its reorder level. That check comes before the days-left check.

The exported CSV should contain the same seven items.
